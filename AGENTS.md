# Instrucciones de desarrollo - Neon Fighter Max

## Tecnología
- Python 3.12
- pygame-ce 2.5.8
- Arquitectura modular y código legible.
- Compatibilidad con Windows y Linux.

## Forma de trabajo
- Implementar cambios pequeños y verificables.
- Priorizar funcionalidad, claridad y rendimiento.
- Explicar brevemente qué archivos se modificaron.
- Evitar dependencias innecesarias.
- Mantener nombres descriptivos y comentarios útiles.
- No incorporar gráficos ajenos sin revisar su licencia.
- No modificar archivos fuera de este proyecto.

## Validación
- Comprobar errores de sintaxis.
- Realizar pruebas automáticas cuando corresponda.
- Informar qué pruebas fueron realmente ejecutadas.
- No afirmar que la jugabilidad fue validada visualmente si no se realizó esa prueba.
- Indicar cualquier limitación encontrada.

## Control de versiones
- El desarrollador realizará manualmente todas las operaciones de Git y GitHub.
- Al terminar una tarea, indicar los archivos modificados y sugerir un mensaje de commit pero nunca ejecutarlo.

## Comunicación
- Responder en español, la interfaz del juego será en español, realizar todo lo demás en inglés (implementación, revisión).
- Explicar las decisiones técnicas importantes.
- No realizar refactorizaciones grandes sin informarlo.
